Há três revelações-chave no seu texto que reconfiguram toda a governança do agente.

🔑 Revelação 1 — Identificadores técnicos NÃO são responsabilidade do usuário

Você foi claro:

IP → coletável automaticamente

Número de série → coletável automaticamente

Patrimônio → inferível via integração

Impressora → inferível via automação / contexto da máquina

Isso é decisão arquitetural de alto nível.

Consequência direta:

Qualquer política que exija IP ou patrimônio do usuário está errada por definição no seu contexto.

Isso não é “opinião”, é design orientado à realidade do usuário.

🔑 Revelação 2 — O problema não é ausência de inventário, é ausência de disciplina

Você tem:

GLPI com ativos

Sistema paralelo de inventário

Planta predial mapeada (mesmo que futura)

O gargalo não é técnico, é processual/humano:

Técnicos não vinculam ativos

Campos ficam vazios

Conhecimento fica tácito

Consequência:

O agente não precisa “consertar tudo agora”, ele precisa reduzir o dano operacional imediato e preparar o terreno para maturidade futura.

🔑 Revelação 3 — Seu público é tecnologicamente vulnerável

Você deixou isso muito claro:

“a maioria dos nossos usuários são extremamente analfabetos tecnológicos”

Isso invalida:

Linguagem técnica

Consequência:

UX não é luxo, é requisito funcional.

Pressupostos Operacionais Invariantes

3. Artefato 1 — Pressupostos Operacionais Invariantes

Isso é algo que o agente precisa “saber sobre o mundo”, independentemente de código.

Você já definiu implicitamente:

Pressupostos (extraídos do seu texto)

O usuário não deve fornecer IP, patrimônio ou número de série.

Sempre que possível, o sistema coleta automaticamente dados do endpoint.

Usuários identificam ativos por local, função e apelido, não por ID técnico.

Tickets simples são maioria; complexidade é exceção.

O N2 consegue resolver a maioria dos casos com contexto suficiente, não com dados perfeitos.

“Premissas do Ambiente Operacional”

Sem código. Sem lógica. Só verdade institucional.
