# 06 — Regras de Inferência

## Quando o agente PODE inferir
- Contexto implícito (“ele”, “aquela” referindo à impressora)
- Default de urgência: Média
- Default de impacto: Individual
- Regras de datas vagas (ex.: “semana que vem”)

## Regras proibidas
- Não assumir identificadores (CPF, IP)
- Não assumir intenções ambíguas
- Não inferir sem contexto
